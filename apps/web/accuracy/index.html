Return to Sol

Astronomical comparison evidence

Sol records independent comparisons of its native geometric position output with retained NASA/JPL Horizons DE441 vectors. These are measurements at 160 discrete samples: 16 epochs for each of ten explicit target/origin pairs. They do not certify the current displayed UTC date or every date between the samples.

Read the complete independent native comparison records (JSON). Every record retains the exact epoch, target, origin, reference and native vectors, residuals and acceptance result. The registry also contains source and provenance hashes. The original responses, query URLs, acquisition metadata and predeclared comparison plan are retained under tests/fixtures/horizons-vectors-20261104 in the corresponding source distribution.

The retained full-calendar matrix includes failed samples at remote epochs. Failed observations remain in the registry with passed: false; they cannot qualify a selection. Evidence integrity and passing a numerical accuracy budget are separate results.

What was compared

The quantity is geometric Cartesian position in AU, using the ecliptic of J2000, ICRF X axis and IAU76 obliquity. Light-time and apparent-position corrections are absent. Nine cases are heliocentric; the tenth is the Moon relative to Earth's centre. Several planetary reference targets are system barycentres, as their explicit Horizons target IDs show.

The reference epochs are in TDB. The native probe sets its TT model argument numerically equal to that reference epoch, with recorded numerical mismatch below 0.001 seconds. This retains the approximate TT/TDB equivalence (up to about 2 milliseconds); it does not independently validate ancient or future UTC/UT1 conversion.

Three distinct residuals

  • Relative vector residual, arcsecond-equivalent: the length of the vector difference divided by reference distance, multiplied by arcseconds per radian. The predeclared sample budget is at most 10.0. This metric includes distance error and is not angular separation.
  • Angular separation, arcseconds: the angle between the native and reference direction vectors. No separate acceptance threshold is assigned.
  • Radial residual, parts per million: signed relative distance error. No separate acceptance threshold is assigned.

Limits and reproducibility

Only the native f64 System ABI was numerically compared. A release's WASM receipt binds corresponding scientific sources and binary hashes; it does not measure agreement between native and WASM results. These records do not qualify apparent sky directions, observer altitude, refraction, velocities, events, image rendering or a continuous epoch range.

The offline validator rejects changed scientific sources, reference artifacts, sample identities and stored residuals. From the corresponding source tree, run python tools/validate_independent_vector_evidence.py --replay to reproduce the native comparison with the locked offline Rust toolchain. Add --require-all-pass to enforce the unchanged 10.0 sample budget for the complete matrix; retained deep-time failures make that gate fail. Regeneration after scientific changes uses python tools/generate_independent_vector_evidence.py.

The separate TOP2013 source-theory parity records compare an implementation with its source theory. They remain distinct from independent astronomical comparison evidence.
