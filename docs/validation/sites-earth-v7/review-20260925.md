## Changes

1. Earth keeps its registered surface demanded while the July map or optional
   shader is loading or unavailable. The source disclosure identifies that fallback.
   Ready July rendering withdraws registered-surface demand through the existing
   bounded cache. Regression tests cover loading, decode failure, shader failure,
   selector retry and return to the Sites recipe.
2. `tools/illustrative_look_probe.mjs` runs after the existing scene and Earth
   assertions. It identifies actual Mercury/Venus draws from their submitted model
   positions, verifies texture and shader modes, checks GL errors, and verifies
   the Venus shell does not write depth. The radar-plus-shell frame is compared
   with Source-qualified at the same camera, epoch and physical positions.
   Screenshots and `illustrative-looks.json` are retained with browser CI evidence.
3. The Earth volume adapter requires exactly one source footprint match and
   rejects residual lab camera uniforms. Tests change the imported recipe to
   prove missing, duplicated and incomplete adaptations fail before GPU compilation.
4. Earth optical status is set during demand synchronization. The redundant
   terrain-status assignment is removed from `drawEarthLook`; the ordinary body
   path already establishes the value. The draw no longer writes either status.
