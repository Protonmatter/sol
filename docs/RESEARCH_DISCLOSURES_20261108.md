# Research disclosure reachability correction

The bounded desktop Inspector is a flex column. Its Sun disclosure sections
also have hidden overflow, which permits their automatic minimum flex height
to collapse. The recorded baseline reduces each section to a 2 px border box
while its summary remains about 43 px high; content is clipped and native
wheel/pointer interaction cannot reach it.

The local correction prevents those sections from shrinking. Their content
contributes to the Inspector scroll range. It preserves the default open region
section, native details/summary behavior, model/source data, drawing commands,
approved Illustrative Earth and all existing controls.

The full browser validator now checks native wheel reachability, pointer and
Enter activation for all four Sun summaries, plus native region search and
clearing. It restores the original disclosure states and records trusted events,
clipping intersections and hit targets. Nonzero bounding boxes, programmatic
focus and HTMLElement.click alone do not prove pointer reachability. The helper
is included in the validator's source hash ledger; existing gates remain.
